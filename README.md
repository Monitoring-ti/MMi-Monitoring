# MMI by Monitoring

Aplicación web comercial de **Monitoring Maintenance Intelligence** para el sector minero.

Conecta SAP PM, FMECA, manuales OEM e historial de mantenimiento para transformar información dispersa en conocimiento operativo respaldado por evidencia.

## Uso local

```bash
npm install
npm run dev
```

La configuración privada de publicación no forma parte de este repositorio público.
